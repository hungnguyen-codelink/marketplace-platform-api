      - "Different client IPs maintain separate counters in Redis"
      - "When Redis is down (connection unavailable), all requests pass through with X-RateLimit-Status: DEGRADED header"
      - "Middleware is registered in app.ts before all route handlers (auth, shops, products, etc.) and before /health endpoint"
      - "Rate limit applies uniformly regardless of route or HTTP method"
      - "Counter increments for all requests (GET, POST, PUT, DELETE, etc.) on the same IP"
